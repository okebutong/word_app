# 单词诊断 WordCheck

用固定节点（第 1/2/4/7/15/30 天）复习一小批单词，统计每个节点的记住率，判断遗忘发生在前几天还是更久以后。

## 编译

推到 GitHub 的 `main` 分支后，Actions 会自动编译：
- **Releases → latest** 里的 `WordCheck.apk`：手机浏览器打开 Releases 页面就能直接下载
- Actions 运行页里的 artifact（zip 包）

## 用法

- **添加新词**：添加当天算第 0 天，添加的时候顺便学一遍。例句可选；变形词用 `*星号*` 标出，比如 `She *ran* home.`
- **开始复习**：看到高亮词就开始计时，说出意思后点“显示释义”，然后按 3 秒标准选“记住了”或“没记住”
- **节点统计**：每个节点的次数、记住率、3 秒内记住率
- **导出 CSV**：通过分享发到微信、邮件等，也可以当备份用

漏掉的节点不补：比如第 2 天和第 4 天都没复习，第 5 天打开时这次复习记在第 4 天节点上，CSV 里的 `days_late` 会记录晚了几天。

## 注意

- 数据存在 App 私有目录里，**卸载就没了**。出差前和中途记得导出 CSV。
- `app/debug.keystore` 是固定签名，保证每次编出来的新版本能直接覆盖安装、不丢数据。不要删。仓库建议设成私有。
